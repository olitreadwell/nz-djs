# Glossary map

This monorepo has two bounded contexts. Read the glossary for the package you
are changing.

| Context | Glossary | What it covers |
| --- | --- | --- |
| `kiwi-djs` | `packages/kiwi-djs/GLOSSARY.md` | DJs, mixes, events, venues, soundsystems, orgs |
| `kiwi-fests` | `packages/kiwi-fests/GLOSSARY.md` | festivals, editions, promoters, artists, lineups |

System-wide decisions live in `docs/adr/`. Context-specific decisions stay
inside the package's own docs.
