# Glossary: kiwi-djs

Terms used by the DJ directory. Use these names in issues, tests and code.

- **DJ** — a person or act with a public profile in the directory. The primary
  directory entity.
- **Mix** — a published recording or stream attached to a DJ.
- **Event** — a dated gig with a venue and, where known, a lineup of DJs.
- **Venue** — a physical place that hosts events.
- **Soundsystem** — a crew or rig that provides sound, distinct from a venue.
- **Org** — a collective, label, promoter or business connected to DJs.
- **Profile tier** — the completeness band assigned to a DJ profile.
- **Snapshot mode** — serving the committed `src/data/snapshot.json` when no
  `DATABASE_URL` is set.
- **Postgres mode** — serving live rows through the repository adapters when a
  database URL is configured.
- **Opt-out** — a DJ's permanent request to be hidden from public queries.
