# Glossary: kiwi-fests

Terms used by the festival directory. Use these names in issues, tests and
code.

- **Festival** — a recurring NZ music event with one or more editions.
- **Edition** — one year's running of a festival, with dates and a lineup.
- **Promoter** — the company or collective that runs a festival.
- **Artist** — a DJ or act booked on a lineup.
- **Lineup** — the join between an artist and a festival edition, optionally
  carrying stage and set times.
- **Stage** — a named performance area within a festival edition.
- **Set time** — the published start and end of one lineup entry.
- **Snapshot mode** — serving the committed `src/data/snapshot.json` when no
  `DATABASE_URL` is set.
- **Dataset** — the validated collection of festivals, promoters, artists and
  lineups that every page and feed reads.
